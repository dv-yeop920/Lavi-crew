# 002. 관리자와 알바를 라우트로 분리

## 상태

확정 (2026-07-15)

## 배경

알바와 단일 관리자는 서로 다른 작업 화면이 필요하지만 인증, 공지, 스케줄, 출석, 급여 도메인을 공유한다.

## 결정

- 하나의 Next.js 애플리케이션을 유지한다.
- 공통 로그인 화면은 `/`, 알바 화면은 `/home`, 관리자 화면은 `/admin` 아래에 둔다.
- Route Group과 Layout으로 화면 구성을 분리한다.
- 서버 Layout과 Controller에서 역할을 확인하고, 데이터 접근의 최종 경계는 Supabase RLS로 강제한다.

## 이유

- 공통 도메인과 UI를 중복 구현하지 않는다.
- 역할별 화면 탐색 구조를 명확히 유지한다.
- URL이나 UI 숨김에만 의존하지 않고 서버와 DB에서 권한을 재검증할 수 있다.

## 포기한 대안

- 관리자·알바 앱을 별도 저장소로 분리: 공통 기능과 배포 구성이 중복된다.
- 로그인 후 한 화면에서 조건문으로 모든 UI 전환: 역할별 레이아웃과 접근 경계가 불명확해진다.

## 결과

역할 전용 화면은 각 Route Group에 두되, 업무 로직은 역할별 페이지가 아니라 기능 Controller와 Domain에 둔다.
