# 라비크루 도메인 용어

| 용어 | 의미 |
| --- | --- |
| 알바(`worker`) | 월별 주말 근무를 신청하고 자신의 확정 스케줄·출석·급여·공지를 조회하는 구성원 |
| 관리자(`admin`) | 한 명의 팀장. 신청 마감, 배정, 출석 확정, 시급, 공지, 알바 목록을 관리하는 구성원 |
| 스케줄 신청 | 알바가 특정 근무일에 일할 수 있다고 제출한 의사 표시 |
| 신청 취소 | 신청 마감 전에 알바가 신청한 날짜의 근무 가능 의사를 철회하고 변경 내용을 저장하는 처리 |
| 신청 마감 | 관리자가 대상 월 전체의 스케줄 신청·취소를 더 이상 받지 않도록 전환한 상태 |
| 배정 | 관리자가 해당 날짜 신청자를 특정 날짜·시간·포지션에 배치한 기록 |
| 확정 스케줄 | 관리자가 등록해 구성원에게 공개한 배정 집합 |
| 교육 배정 | 신규·교육 대상 근무임을 배정에 함께 표시한 상태 |
| 가능 포지션 | 관리자가 구성원별로 실제 수행할 수 있다고 설정한 포지션 목록. 스케줄 인원 선택 시 배정 판단 정보로 사용 |
| 운영 포지션 | 팀장·스캔·메인·드레스·축가·매니저·안내·대기실로 고정된 8개 역할. 추가·삭제·비활성화하지 않으며 시급을 보유하지 않음 |
| 출석 확정 | 관리자가 실제 출근 여부와 확정 근무 시간을 기록한 상태 |
| 정정 | 출석 확정 이후 이력을 삭제하지 않고 관리자가 사유와 함께 수정하는 흐름 |
| 개인 시급 | 관리자가 인원별로 등록·수정하고 해당 구성원이 조회하는 시간당 급여 |
| 초과근무 | 하루 확정 근무시간 중 9시간을 넘는 부분. 해당 인원의 개인 시급 1.5배를 적용 |
| 확정 급여 | 출석 확정 시간과 배정 확정 시점의 개인 시급을 기준으로 계산한 실제 근무 급여 |
| 비활성화 | 관계 이력을 보존하면서 회원의 로그인과 신규 활동을 중단하는 상태 |
| 회원 삭제 | 관리자 화면의 사용자 표현. 실제 처리는 근무·출석·급여 이력을 보존하는 계정 비활성화 |

화면 문구, 타입, DB 상태 이름이 이 용어와 다른 의미를 만들게 되면 요구사항과 함께 이 문서를 갱신한다.
